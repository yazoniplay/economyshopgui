# EconomyShopGUI v6-style configuration template

This folder is an original v6-style configuration template for EconomyShopGUI.

Structure:
- config.yml
- shops/
- sections/

It is intentionally not a copy of a third-party server's configuration. Prices and categories here are placeholders that can be replaced for AdderallMC.

Important: the v6 plugin jar itself may not load on a modern Paper version. This repository only contains configuration files.

Reference for the v6 separated shops/sections format:
https://wiki.gpplugins.com/economyshopgui/file-configuration/sections.yml
https://wiki.gpplugins.com/economyshopgui/file-configuration/shops.yml
